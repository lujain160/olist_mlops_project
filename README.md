# Olist Delivery Late Prediction - MLOps Project
An MLOps machine learning project designed to predict delivery delays for Olist orders.

## Project Structure
The project directory is organized as follows:
* `app/`: Contains application scripts and final deployment interfaces.
* `config/`: Contains centralized configuration files (`config.yaml`).
* `data/`: Stores raw datasets, processed split files (Train/Val/Test), and data loader.
* `models/`: Stores trained models and preprocessors (e.g., joblib files).
* `notebooks/`: Dedicated to exploratory data analysis and interactive Jupyter notebooks.
* `src/`: Core source code for data processing, training, and configuration loading.
* `tests/`: Contains code quality tests and unit tests.
